<h1>RAG 기반 사용자 맞춤형 컴퓨터 보안 안내 시스템</h1>

<p align="center">
본 프로젝트는 <strong>사용자 개인 Desktop 환경에 맞는 보안 안내</strong>를 제공하는 RAG 기반 시스템입니다.<br />
보안 설정을 정확히 이해하지 못한 채 변경하면 개인 PC의 보안 수준이 낮아질 수 있으며,<br />
기존 LLM은 실제 환경 정보를 알지 못해 추가 질문이나 부정확한 답변이 발생할 수 있습니다.<br />
<br />
이에 본 시스템은 <strong>사용자 질문, Desktop 설정값, 공식 보안 문서</strong>를 함께 활용하여<br />
사용자 환경에 맞는 근거 기반 답변을 생성하고,<br />
할루시네이션과 보안사고 가능성을 줄이는 것을 목표로 합니다.
</p>
