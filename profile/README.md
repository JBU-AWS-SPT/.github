<h1>RAG 기반 사용자 맞춤형 컴퓨터 보안 안내 시스템</h1>

<p align="center">
본 프로젝트는 <strong>사용자 개인 Desktop 환경에 맞는 보안 안내</strong>를 제공하기 위한 RAG 기반 시스템입니다.<br />
일반 사용자가 보안 설정이나 애플리케이션 사용 과정에서 정확한 이해 없이 설정을 변경할 경우,<br />
오히려 개인 PC의 보안 수준이 낮아질 수 있다는 문제에서 출발했습니다.<br />
<br />
기존 LLM은 사용자의 운영체제, 보안 설정, Defender 상태 등 실제 환경 정보를 알지 못하기 때문에<br />
사용자가 여러 차례 추가 질문을 해야 하거나, 보안적으로 부정확한 답변이 생성될 수 있습니다.<br />
또한 공식 문서가 존재하더라도 방대한 문서 속에서 상황에 맞는 내용을 직접 찾고 적용하는 과정은 비효율적입니다.<br />
<br />
이에 본 시스템은 <strong>사용자 질문, Desktop 설정값, 공식 보안 문서</strong>를 함께 활용하여<br />
사용자 환경을 고려한 맞춤형 답변을 생성하고,<br />
RAG 기반 문서 검색을 통해 할루시네이션과 보안사고 가능성을 줄이는 것을 목표로 합니다.
</p>
